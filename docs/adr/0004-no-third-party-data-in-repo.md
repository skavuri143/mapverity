# ADR 0004: No third-party datasets in the repository

**Status:** Accepted, 2026-10-30

## Context
The defect-risk model trains on public NASA MDP data. Redistribution terms for derived versions
are not uniformly documented, and healthcare and insurance examples must never contain real records.

## Decision
Download third-party data at run time from a documented source, verify recorded SHA-256 checksums,
and document provenance. All example and test data is generated by scripts in the repository.

## Consequences
Training needs network access once (cached afterwards). Results are reproducible because files
are checksum-pinned. The repository is safe to share and fork.
