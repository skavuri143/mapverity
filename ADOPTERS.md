## Adding your organization

Open a pull request adding a row, or use the "Adoption report" issue template. Useful details:

- the pipeline and data shape (for example "partner flat files → Spark → Postgres")
- which MapVerity features you use (mapping checks, mutation testing, gates, prioritization...)
- since when, and in which environment (pilot, pre-production, production)
- any measured effect you are comfortable sharing, and how you measured it

Only list what is true today; describe pilots as pilots. Please do not share data, schemas or
details your organization considers confidential. See
[docs/case-study-template.md](docs/case-study-template.md) if you would like to write up a case study.
