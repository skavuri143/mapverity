# Examples

All data is generated by the scripts here; nothing is real.

| Example | Domain | Sources → target | Shows |
|---|---|---|---|
| [`member_eligibility/`](member_eligibility/) | health benefits (member eligibility) | EBCDIC COBOL member master + pipe-delimited eligibility → member JSON documents (DocumentDB) | copybooks, COMP-3, selection filters, nested arrays, 20 seeded defects, risk scoring of transform functions, reference AWS Glue job |
| [`insurance_claims/`](insurance_claims/) | health insurance claims | multi-record fixed-width claims file (HDR/CLM/LIN/TRL) + policy extract → claim JSON documents | layouts, signed implied decimals, trailer control totals, foreign keys, ICD-10 formatting, 10 seeded defects |
| [`docker_demo/`](docker_demo/) | | member pipeline against a live MongoDB (DocumentDB stand-in) | `docdb` reader end to end with Docker Compose |
