# Support

MapVerity is maintained on a best-effort basis by volunteers.

| Need | Where | Expected response |
|---|---|---|
| Question or "how do I...?" | GitHub Discussions (Q&A) | within a week |
| Bug | GitHub Issues, using the bug template, with synthetic data | triaged within a week |
| Security issue | see [SECURITY.md](SECURITY.md) | acknowledged within 3 business days |
| Feature request | GitHub Issues, using the feature template | discussed in the next roadmap review |
| Telling us you use MapVerity | the "Adoption report" issue template or a Discussion | always welcome |

**Never attach real personal, member, patient, policyholder or financial records** to an issue,
discussion or pull request. Reduce the problem to generated data; the example generators in
`examples/` are a good starting point.

There is no commercial support offering. The project does not provide legal, regulatory or
compliance advice, and passing MapVerity checks is not a certification of any kind.
